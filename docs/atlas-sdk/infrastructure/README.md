# Infrastructure

These docs describe how the Atlas SDK package should be organized, built,
tested, and connected to Atlas Core.

Read these when changing package structure or shared SDK behavior.

## Files

- `naming.md`: product and package naming.
- `source-inventory.md`: older Atlas sources reviewed during planning.
- `carry-forward.md`: useful ideas carried into this SDK.
- `rejected-ideas.md`: older ideas intentionally rejected or deferred.
- `public-surface.md`: public exports and namespace shape.
- `internal-modules.md`: likely internal module map.
- `boundaries.md`: what the SDK owns and does not own.
- `transport.md`: fetch wrapper, config, auth header, and raw escape hatch.
- `errors.md`: SDK error behavior and Core error preservation.
- `testing.md`: SDK test strategy.
- `build-and-package.md`: TypeScript/npm build direction.
